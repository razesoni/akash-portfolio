# Akash — Portfolio

Personal HTML, CSS and JavaScript portfolio. The entry point is `index.html`; styles, scripts and assets are in their respective directories.

## Run locally

From the repository root:

```bash
python -m http.server 8080
```

Open http://localhost:8080. No application backend is included. Third-party images, music and other assets retain their respective rights.
